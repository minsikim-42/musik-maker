# music-maker

브라우저에서 여는 작곡(시퀀서) 앱. **악기를 고르고 → 격자(피아노 롤)에 음표를 찍고 → 재생하면 곡이 흘러나온다.**
링크 하나로 폰·태블릿·다른 PC 어디서든 접속하는 것이 목표.

- 소리 엔진: [Tone.js](https://tonejs.github.io/) (Web Audio API 위에서 악기·타이밍·재생을 다룸)
- 화면: HTML + CSS + 바닐라 JS (프레임워크 없이 시작)
- 별도 빌드 도구 없음 — `index.html`을 브라우저로 열면 바로 돈다

## 실행

`index.html`을 브라우저로 열거나, 로컬 서버로 띄운다:

```bash
python3 -m http.server 8000
```

그 다음 http://localhost:8000 접속. (첫 재생 버튼 클릭 때 소리가 켜진다 — 브라우저 정책상 사용자 클릭이 있어야 오디오가 시작됨)

## 로드맵

- [x] **1단계** — 악기 하나(피아노) + 격자 + 재생. 클릭한 음이 순서대로 소리남
- [x] **2단계** — 여러 트랙, 템포·곡 길이 조절, 왼쪽 햄버거 메뉴
  (트랙은 **＋ 트랙 추가**로 만들고, 사운드(피아노·신스·베이스·드럼 등)는 트랙 드롭다운에서 고른다)
- [x] **3단계** — 곡을 "세션"처럼 저장/전환 (왼쪽 드로어 = 내 곡 목록, localStorage 자동 저장)
- [x] **4단계** — 링크로 공유 → 다른 기기에서 같은 곡 열기 (서버 없이 URL에 곡을 담음)
- [x] **5단계** — 신디사이저(음색 편집): 멜로디 트랙 악기 "커스텀 🎹" + 파형·ADSR·컷오프·볼륨 편집
- [ ] (나중에) 환경설정, 오선지 악보 보기, WAV로 내보내기

### 신디사이저 (음색 편집)

- 멜로디 트랙 악기를 **"커스텀 🎹"**으로 고르면 트랙 헤더에 **🎹 음색** 버튼이 뜬다(또는 왼쪽 메뉴 🎹).
- 편집기: **파형**(사인/삼각/사각/톱니) + **ADSR**(어택·디케이·서스테인·릴리스) + **컷오프**(로우패스, 밝기)
  + **볼륨**. 슬라이더를 움직이면 `applyParamsLive`로 **소리에 즉시 반영**(신스 재생성 없이 `poly.set`).
- 파라미터는 트랙에 `params`로 붙어 **세션 저장(localStorage)** 되고, **공유 링크에도 실린다**(코덱 v2).
  링크에서는 7바이트로 양자화(파형 1 + ADSR 4 + 컷오프 1 + 볼륨 1) — 링크를 짧게 유지하는 대신 값이
  아주 미세하게 바뀔 수 있다(귀로는 구분 안 됨). v1 링크도 계속 열린다(하위호환).

### 링크 공유 방식 (다른 기기)

- **서버 없음.** 곡(트랙·악기·격자·템포·마디)을 **비트로 패킹→base64**해서 URL 해시(`#song=...`)에 담는다.
  격자가 불리언이라 그대로 두면 링크가 길어지므로 비트 패킹으로 짧게 유지한다(2트랙 2마디 ≈ 150자).
- 공유 버튼(상단 `🔗 공유` 또는 왼쪽 메뉴) → 링크 복사 → 나에게(카톡·메일 등) 보내 다른 기기에서 연다.
- 링크로 접속하면 그 곡을 **새 세션으로 내 곡 목록에 담고** 연다(주소창의 코드는 정리).
- **전제: 다른 기기에서 열려면 앱이 공개 주소에 있어야 한다.** localhost 링크는 그 컴퓨터에서만 열린다.
  → 아래 "배포" 참고.
- 코덱은 `encodeShare`/`decodeShare`(app.js). 버전 바이트가 있어 나중에 포맷이 바뀌어도 구분 가능.

## 배포 (다른 기기에서 실제로 쓰려면)

정적 파일뿐이라 아무 정적 호스팅에나 올리면 된다. 가장 쉬운 건 **GitHub Pages**:

1. 이 폴더를 GitHub 저장소로 push
2. 저장소 Settings → Pages → Branch를 `main`/`root`로 지정
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소>/` 로 열림 → 이 주소에서 공유하면 폰에서도 열린다

(아직 push 안 함. 원하면 도와줄 수 있음.)

### 세션(내 곡) 저장 방식

- 곡 하나 = 세션 하나. 트랙·악기·격자·템포·마디를 통째로 **브라우저 localStorage**에 담는다
  (키: `music-maker.sessions`, 활성 곡: `music-maker.activeId`).
- **자동 저장**: 편집하면 400ms 뒤 활성 곡에 저장(연속 편집을 모아 한 번에). 저장 버튼 없음.
- 왼쪽 햄버거 → "내 곡" 목록에서 곡을 눌러 전환, `＋ 새 곡`으로 추가, ✎로 이름 변경(인라인),
  🗑로 삭제(실행취소 토스트 포함).
- **주의**: localStorage는 이 브라우저에만 저장된다. 다른 기기/브라우저에서는 안 보인다 →
  그건 4단계(클라우드+링크)에서 해결.

## 용어

- **피아노 롤**: 가로=시간(칸), 세로=음 높이. 칸을 클릭해 음표를 켜고 끈다. 오선지보다 쉬워서 여기서 시작.
- **스텝(step)**: 격자의 한 칸. 재생하면 왼쪽부터 오른쪽으로 한 칸씩 지나간다.
- **BPM(템포)**: 1분에 몇 박자인지. 클수록 빠르다.
